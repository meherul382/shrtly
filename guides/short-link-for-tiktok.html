How to Create a Short Link for TikTok

A short URL can make a TikTok profile or public video address easier to share outside TikTok. The original TikTok URL remains the destination.

Copy the TikTok URL

Use TikTok's share option to copy the public URL you want to share.

Shorten it

Paste the address into Shrtigo and generate a short URL. A custom alias can make a profile or campaign link easier to remember.

Test before posting

Open the generated link and confirm that it reaches the intended TikTok page. Avoid using misleading aliases or links to unrelated destinations.

Where to use it

Short links can be useful in websites, email, printed material and messages where a compact address is easier to handle.
