How to Create a Custom Short URL for Your Brand

A custom short URL replaces a random-looking code with a memorable alias. For campaigns and content sharing, a clear alias can help people recognize the purpose of a link before opening it.

What is a custom short URL?

It is a shortened address where the final code is chosen by the creator rather than generated randomly. Availability and naming rules still apply.

Why use a custom alias?

A relevant alias can be easier to remember, easier to communicate verbally and more consistent across a campaign. It can also make a shared link look more organized.

How to create one with Shrtigo

Enter your destination URL, enable the Custom link option and choose an available alias. Keep it concise and connected to the destination. Generate the link and test it before publishing.

Tips for better aliases

Use readable words, avoid unnecessary punctuation, keep spelling simple, and avoid names that could be confused with another organization. Never use an alias that intentionally misrepresents the destination.

FAQ

Can two links use the same alias? No. A short code must be unique.

Can I change an alias later? Availability and service rules determine whether a new link can be created; do not assume an existing link can be renamed.
