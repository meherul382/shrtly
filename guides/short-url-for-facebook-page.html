How to Shorten a Facebook Page URL

A Facebook Page address can be shortened for cleaner sharing outside Facebook. The short URL should always lead to the intended public Page.

Copy the Page URL

Open the public Facebook Page and copy its address.

Create the short link

Paste the Page URL into Shrtigo and generate a short URL. A descriptive alias can make the link easier to remember.

Test it

Open the short link on mobile and desktop before publishing. Confirm that the correct Page opens.

Share with context

Use a short description alongside the link so recipients know what they are about to visit.
